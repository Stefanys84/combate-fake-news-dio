# Miniguia de Estudos: O Combate às Fake News 🕵️‍♂️🔎

## 1. Contexto e Objetivos
**Contexto:** O ecossistema digital atual sofre com a rápida disseminação de notícias falsas (Fake News). Este caderno temático foi criado para entender como a desinformação funciona, como ela afeta a sociedade e quais são as ferramentas e métodos práticos para identificar e combater essas narrativas.

**Objetivos de Estudo:**
* Compreender os mecanismos de criação e propagação de Fake News.
* Aprender técnicas práticas de checagem de fatos (Fact-checking).
* Desenvolver senso crítico na curadoria e consumo de informações na internet.
* Utilizar a IA como ferramenta de apoio para estruturar métodos de verificação.

## 4. Miniguia de Estudo (Entrega Final)

### 4.1. Resumo Estruturado
Para combater a desinformação:
* **Leia além do título:** Não compartilhe baseando-se apenas em manchetes sensacionalistas.
* **Verifique a fonte:** Sites desconhecidos exigem cautela.
* **Cheque a data:** Notícias antigas podem ser usadas fora de contexto.
* **Consulte o especialista:** Utilize portais de fact-checking como o *Aos Fatos*.

### 4.2. Glossário
* **Fake News:** Informação fabricada para enganar.
* **Fact-checking:** Verificação profissional de alegações factuais.
* **Desinformação:** Informação falsa criada com intenção deliberada de causar dano.
